# DemoBlaze E-Commerce Website – Manual Testing

## Project Overview

This project focuses on manual testing of the DemoBlaze e-commerce website.

The objective was to verify the functionality, usability, navigation,
forms, cart, ordering process, and UI components of the application.

## Application

DemoBlaze E-Commerce Website 
https://demoblaze.com/ 

## Testing Type

- Manual Testing
- Functional Testing
- UI Testing
- Positive Testing
- Negative Testing
- Regression Testing

## Tools Used

- Microsoft Excel
- Microsoft Word
- GitHub
- Browser DevTools
